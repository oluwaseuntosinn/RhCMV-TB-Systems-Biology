# RhCMV-TB Systems Biology Workflow

Reproducible R workflow for longitudinal systems-vaccinology analysis of RhCMV-TB vaccination transcriptomic data.

## Overview

This repository contains scripts used to analyse longitudinal whole-blood/PBMC transcriptomic responses following RhCMV-TB vaccination. The workflow integrates differential expression analysis, weighted gene co-expression network analysis (WGCNA), module preservation assessment, trajectory analysis, functional enrichment, and hub gene identification.

## Workflow Components

1. Metadata preparation
2. Expression matrix construction and preprocessing
3. WGCNA module discovery
4. Module eigengene trajectory analysis
5. Module preservation analysis
6. Vector dynamics and mixed-effects modelling
7. Functional enrichment analysis
8. Hub gene identification

## Repository Structure

- `scripts/` – Analysis scripts
- `manuscript/` – Manuscript and supporting files
- `README.md` – Project documentation
- `R_reference.bib` – References used in the manuscript
